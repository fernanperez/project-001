# Project-001

## Descripcion del proyecto
Este proyecto consiste en desarrollar un Coin Arena para aprender Unity 6 de forma practica. La idea es crear una base solida en la creacion de juegos simples multijugador, incorporando mecanicas claras, buena estructura del proyecto y preparacion para su exportacion a dispositivos Android.

## Autor
Fernan Perez

## Objetivo
Aprender a utilizar Unity 6 de forma practica.

## Lenguajes manejados
- C#
- HLSL/ShaderLab (Unity shaders)
- JSON (configuraciones y datos)
